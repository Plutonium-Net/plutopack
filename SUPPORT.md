# Support

Need help with PlutoPack? This document explains where to get help and how to report problems.

## Before Asking for Help

Before opening a support request:

* Check the [README](README.md).
* Check the [PlutoPack specification](SPEC.md).
* Search existing issues to see if your problem has already been reported.
* Make sure you are using the latest version of PlutoPack.

## Getting Help

For general questions, usage problems, or help understanding PlutoPack, open an issue in the PlutoPack repository.

When asking for help, include:

* The version of PlutoPack you are using.
* Your operating system and browser, when relevant.
* What you were trying to do.
* What you expected to happen.
* What actually happened.
* Relevant error messages or console output.
* A minimal example that reproduces the problem, when possible.

The more information you provide, the easier it is to diagnose the problem.

## Bug Reports

If you believe you have found a bug, please use the repository's **Bug Report** issue template when available.

Do not use a public issue to report security vulnerabilities. See [`SECURITY.md`](SECURITY.md) for security-related reports.

## Feature Requests

Feature requests are welcome.

Before proposing a new feature, consider whether it fits within PlutoPack's goals and existing specification. Explain:

* What you would like PlutoPack to do.
* Why the feature would be useful.
* How you think it could work.
* Whether the change would affect the PlutoPack format or compatibility.

## PlutoPack Format Issues

If you are having problems with a `.plutopack` file or believe the format is behaving incorrectly, include the package's format/version information and, when possible, a reproducible example.

For issues involving the specification itself, refer to [`SPEC.md`](SPEC.md) before opening a report.

## Security Issues

**Do not report security vulnerabilities through public GitHub issues.**

Please follow the private reporting instructions in [`SECURITY.md`](SECURITY.md).

## Contributing

If you want to help improve PlutoPack, see [`CONTRIBUTING.md`](CONTRIBUTING.md) for information about contributing code, documentation, and other changes.

## Community Guidelines

All interactions within the PlutoPack project are subject to the project's [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Please keep discussions respectful, constructive, and focused on improving the project.

---

If you cannot find an answer in the available documentation, opening an issue is the best way to request help.
